# 9class.org.ua

Стартова сторінка з плитками трьох тренажерів для 9 класу.

| Предмет | Адреса | Код |
|---|---|---|
| Хімія | himiya.9class.org.ua | `nowway-ops/khimik` |
| Фізика | fizyka.9class.org.ua | `nowway-ops/fizika` |
| Математика | matematyka.9class.org.ua | `nowway-ops/matematyka` |

Тут лише статика: один `index.html`, іконка й ці нотатки. Жодних ключів,
даних користувачів чи серверного коду — тому репозиторій може бути публічним,
а сторінка безкоштовно живе на GitHub Pages.

**Чому не Railway:** для кореневого домену Railway вимагає CNAME на `@`, а це
заборонено правилами DNS і не підтримується більшістю реєстраторів, зокрема
укрнеймсом. GitHub Pages віддає звичайні A-записи, які працюють скрізь.
